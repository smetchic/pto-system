# Страница объекта: согласованный вид

Решения от 9 октября 2026 года. Пользователь попросил спроектировать страницу самостоятельно по образцу других разделов и принял результат («запиши»). Макет: https://claude.ai/artifact/Mt45yF3dLQQMKTjsKVpckT (v5; второй договор, субподрядчики, люди и статусы вымышлены). Основа: docs/portfolio.md, docs/conveyor.md, карточка контрагента.

## Общее
- Клик по плитке или строке Портфеля открывает отдельную страницу объекта (не боковую карточку). Крошка «Портфель / Пружаны».
- Шапка: квадратик цвета объекта, название заглавными, имя инженера; справа месяц ‹ Октябрь 2026 ›, статус месяца, кнопка «Объект» (наименование, адрес, инженер, цвет; меняет начальник ПТО, у руководителя кнопки нет).
- Вкладки: **Месяц · Договоры · Документы · История**. Старые «Сводка», «Субподряд», «Процентовки и С-29» убраны: их содержание вошло в «Месяц».
- Всё, что делается, делается в боковой панели `--drawer-w` с «Закрыть ×» слева вверху, как в «Подписании». На странице кнопок шага нет, только строка «Ваш ход».
- Права: инженер работает на своём объекте, начальник ПТО везде, руководитель только смотрит (строка «Ход инженера Нади» вместо «Ваш ход», без кнопок).

## Вкладка «Месяц» (главная, без прокрутки на 24″)
**Заменено 10.10.2026: см. [docs/month.md](month.md) (макет v12, шесть шагов).** Ниже исходный вариант от 9 октября, для истории.

Слева «Работа за месяц», справа узко деньги, договоры, сроки.
1. **Хвост прошлого месяца** : жёлтая полоса над делами, если за прошлый месяц что-то не в бухгалтерии. Пример: «С-29 за сентябрь · проверка ПТО · срок 15.10 через 6 дн.». Прошлый месяц закрывается, когда хвост ушёл в бухгалтерию.
2. **Процентовка заказчику, по одной строке на каждый договор с заказчиком**: у каждой свой шаг из шести, свой «Ваш ход», свои части у технадзора и свой комплект. В правой колонке все договоры с заказчиком с освоением против срока.
   Внутри строки: шкала шести шагов с датами; «Ваш ход» и красным причина, почему дальше нельзя; две колонки: «Части у технадзора · прошли N из M» (наша часть и каждый субподрядчик, сумма, флажок замечания) и «Комплект заказчику · готово N из M» с ссылкой «состав».
3. **С-29 за месяц**: шаг, срок 15-е следующего месяца, основание.
4. **Закрытие месяца**: условия списком; кнопки «Проверить месяц» и «Закрыть месяц» только у начальника ПТО в панели.
5. **Другие дела месяца**, нижняя полоса из трёх клеток: оценка выполнения (предварительно, до актов), допсоглашение в работе (свой маршрут: подготовлено, согласование, подписание, подписано), сопоставление субподряда.
Справа: деньги месяца (СМР ▲/▼, ≈ своими, субподряд «подали N из M», к оплате по С-3а с расшифровкой), договоры с заказчиком (стоимость по ДС, срок, освоение против срока), ближайшие сроки.

## Вкладка «Договоры»
Таблица, две группы: «С заказчиком · мы субподрядчик» и «Субподряда · мы генподрядчик» (роль по договору). Колонки: договор, сторона, части и НДС, стоимость по подписанным ДС (ДС в работе подписью рядом), срок, освоено против срока, состояние за выбранный месяц. Фильтр «Действующие / Завершённые», кнопка «Добавить договор». Строка открывает карточку договора: данные списком, части с НДС, допсоглашения, состав комплекта, «Изменить».

## Вкладка «Документы»
Документы выбранного месяца по комплектам (процентовка заказчику по договору, субподрядчики, хвосты прошлого месяца). Колонки: документ, версия, сумма, где сейчас, скан, кто и когда изменил. Недостающий обязательный документ виден серой строкой («Справка С-3а · нужна для отправки заказчику»). Фильтр «Октябрь / Все месяцы / Договоры и ДС». Карточка документа: версии, скан с хэшем, комплект, «Новая версия».

## Вкладка «История»
Журнал объекта, только добавление. Фильтр: Всё, Шаги, Замечания, Документы, Договоры, Объект. Колонки: когда, что, по чему, кто, комментарий.

## Что нужно в базе (план, миграции только после подтверждения)
Цвет объекта, ожидаемые субподрядчики, части договора с НДС, состав комплекта по договору (правила: всегда, когда есть оборудование, когда есть зачёт, каждый месяц, не нужен; снятие на месяц с причиной), один инженер на объект; у допсоглашения свой маршрут из четырёх шагов (подготовлено, согласование, подписание, подписано), не шесть общих.
