# Документы — оформление v2

Без MutationObserver. Оформление запускается только после пользовательских действий и открытия боковой панели.

Согласовано:
- комплект СУ-22 выше субподрядчиков;
- один общий блок субподрядчиков;
- С-3а выше и визуально заметнее актов С-2;
- часть объекта рядом с актом;
- С-29 не показывается во вкладке «Документы»;
- создание актов/справок внутри содержимого месяца;
- карточка: контрагент → объект → часть объекта → договор → номер документа → месяц;
- статус напротив главной суммы;
- PDF открывается отдельно и может просматриваться слева от карточки;
- импорт Excel не должен автоматически ставить этап проверки.
