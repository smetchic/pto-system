# Раздел «Договоры» (Ещё → Договоры)

Решения 9 октября 2026 года. Макет: https://claude.ai/artifact/1BqtkwZf1VMieS5mkB5wSC. Пользователь выбрал место «в Ещё», рядом с «Объектами». По умолчанию показываются действующие договоры.

## Список
- Все договоры организации, три группы: «С заказчиком», «Субподряда», «Поставка и услуги». Наша роль хранится по каждому договору.
- Фильтры: поиск по номеру, стороне, предмету, объекту; вид; «Действующие / Завершённые / Все»; объект.
- Завершённый договор: срок прошёл, в выбранном месяце по нему нет комплекта, нет допсоглашения в работе. Договор с истёкшим сроком, по которому идёт работа, остаётся в действующих и подсвечивается «Истёк».
- Колонки: договор, объект (цвет и инженер), сторона и роли, стоимость по подписанным ДС (ДС в работе рядом), срок, доля прошедшего срока, состояние за месяц (как на вкладке «Договоры» объекта).
- Над таблицей: сколько с заказчиком и на какую сумму, сколько субподряда, «Срок истёк», «ДС в работе».

## Карточка договора
Боковая панель общей ширины, как у контрагента. Та же карточка открывается со страницы объекта.
- Просмотр: стоимость по ДС с НДС, полоса прошедшего срока, сторона (открывает карточку контрагента), предмет, срок, основной договор, инженер, условия договора, допсоглашения с действиями «Подписано» и «отменить» (с причиной).
- Правка по кнопке «Изменить»: номер, дата, предмет, основной договор, цена и НДС по договору (СМР, ПНР, оборудование), срок по договору. Сторона и объект не меняются. Текущие цена и срок меняются только подписанным допсоглашением.
- Новый договор: объект (только свои), вид договора (роли сторон), сторона из справочника контрагентов, номер, дата, предмет; после сохранения открывается карточка на правку цены и срока.
- Права: начальник ПТО и инженер своего объекта правят, остальные смотрят.

## Ждёт базы (общая миграция треда «Объект в Портфеле»)
Освоение договора (выполнение с начала работ к стоимости), части договора с разным НДС и «Итого по договору», состав комплекта по договору.
