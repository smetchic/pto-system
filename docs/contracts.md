# Раздел «Договоры» (Ещё → Договоры)

Решения 9 октября 2026 года. Макет: https://claude.ai/artifact/1BqtkwZf1VMieS5mkB5wSC. Пользователь выбрал место «в Ещё», рядом с «Объектами». По умолчанию показываются действующие договоры.

## Список
- Все договоры организации, три группы: «С заказчиком», «Субподряда», «Поставка и услуги». Наша роль хранится по каждому договору.
- Фильтры: поиск по номеру, стороне, предмету, объекту; вид; «Действующие / Завершённые / Все»; объект.
- Завершённый договор: срок прошёл, в выбранном месяце по нему нет комплекта, нет допсоглашения в работе. Договор с истёкшим сроком, по которому идёт работа, остаётся в действующих и подсвечивается «Истёк».
- Группы (11.10.2026, демо «Договоры и ДС» v4) названы от лица СУ-22, без номеров уровней: «Заказчик и МПС» (СУ-22 не сторона), «Наш договор с заказчиком», «Наш договор с МПС», «Наши исполнители», «Наши субподрядчики», «Услуги для СУ-22», «Трёхсторонние с МПС». Фильтр — по тем же названиям, только группы, где есть договоры.
- Колонки: договор, объект (цвет и инженер), контрагент, предмет договора, стоимость по подписанным ДС, окончание работ, допсоглашения. Роли сторон — только в карточке.
- «N допсоглашений · M в работе ▸» раскрывает ДС строками под договором: номер, дата, что меняет, «Подписано» / «В работе» / «Отменено». Остальная строка открывает карточку.
- Над таблицей: сколько с заказчиком и на какую сумму, сколько субподряда, «Срок истёк», «ДС в работе».

## Карточка договора
- Допсоглашения по порядку дат: «Договор — начальная цена», каждое ДС, «Действует сейчас — цена по ДС № N» (ДС в работе не учтены).
Боковая панель общей ширины, как у контрагента. Та же карточка открывается со страницы объекта.
- Просмотр: стоимость по ДС с НДС, полоса прошедшего срока, сторона (открывает карточку контрагента), предмет, срок, основной договор, инженер, условия договора, допсоглашения с действиями «Подписано» и «отменить» (с причиной).
- Правка по кнопке «Изменить»: номер, дата, предмет, основной договор, цена и НДС по договору (СМР, ПНР, оборудование), срок по договору. Сторона и объект не меняются. Текущие цена и срок меняются только подписанным допсоглашением.
- Новый договор: объект (только свои), вид договора (роли сторон), сторона из справочника контрагентов, номер, дата, предмет; после сохранения открывается карточка на правку цены и срока.
- Права: начальник ПТО и инженер своего объекта правят, остальные смотрят.

## Части договора
Блок «Части договора» в карточке: название (как в ССР), ставка НДС (0 — без НДС по льготе), стоимость. Акт и С-3а относят к части в «Отметках» документа; в реестре строка на каждую часть и «Итого по договору» (миграция 20261010235000).

## Загрузка из файла (10.10.2026)
Кнопка «Загрузить из файла» (только начальник ПТО) принимает JSON формата pto-contracts v1 (схема /mnt/project-files/contracts/contracts-import.schema.json; файл собирает чат со сканами папки ДОГОВОРА). Предпросмотр по объектам: галочка у объекта (отмечены объекты, которые уже есть в базе), по раскрытию — договоры с пометками «новый», «дополнит пустые поля», «не загрузится» и проблемами (без номера — «б/н», ДС без даты, повтор номера, неверная дата).
Загрузка создаёт недостающие объекты и контрагентов с УНП, договоры, подписанные ДС (кроме signed=false) и части (если их две и больше). Существующий договор ищется по пути папки, затем по объекту, номеру и направлению; у него заполняются только пустые поля. Повторная загрузка того же файла ничего не дублирует.
Новые поля договора: вид (СУ-22 — субподрядчик, СУ-22 — МПС, МПС — заказчик, трёхсторонний), «проверен», путь папки, статус, «заменён», примечание, пути сканов, аванс (текущий %, целевой сумма).
Договоры с низкой уверенностью (из Word-реестров и имён файлов) загружаются «не проверенными»: в списке пометка, в карточке кнопка «Проверен». Непроверенные и справочные (МПС — заказчик, трёхсторонние) в «Подписании» и на вкладке «Месяц» не участвуют; справочные в списке — отдельной группой «Справочно».

## Ждёт базы
Освоение договора (выполнение с начала работ к стоимости), состав комплекта по договору.

## Замечания 11 октября 2026 (карточки договора, ДС и частей)
- «Сканы» в карточке договора называются «Файлы»: пути в папке ДОГОВОРА, при «Изменить» — по одному в строке (команда `set_contract_files`).
- Путь подставляется кнопкой «Выбрать файл…». Chrome и Edge: папка ДОГОВОРА подключается один раз, окно выбора открывается в папке договора. Другие браузеры: папку выбирают один раз за сеанс, файл — из списка с поиском (файлы не загружаются, читаются только пути). Путь хранится от папки ДОГОВОРА без её имени, как у загруженных договоров.
- Ставка НДС не вводится ни в договоре, ни в ДС, ни в части договора: считается НДС / (сумма − НДС) и мелко показывается рядом с полем НДС. Красным — если НДС отличается от 20 % суммы больше чем на рубль, или СМР + ПНР + оборудование (и их НДС) не равны цене. У части договора теперь хранится НДС (`vat_amount`), ставка пишется посчитанной для реестра.
- Все суммы — с разделителем тысяч и при вводе, и при просмотре; ввод с пробелами или без, через точку или запятую.
- Все окна — боковые панели одной ширины («Закрыть ×» вверху слева), центральных окон нет.
