# Проверка сборки 0.1.0

4 октября 2026.

- `npm test`: 9 тестовых групп, 9 успешно. Выполняется SQL миграции в PostgreSQL WASM (PGlite).
- Проверено: доступ по объектам, запрет повышения роли через таблицы, идемпотентность, конфликт ревизий, отдельные передача/получение/подпись/принятие, сохранение принятой суммы при новом черновике, неизменяемые версии, обязательный комплект объекта, закрытие/открытие со снимком, недоступность чужих файлов и доступность своих, суммы субподряда и устаревшие связи, RLS всех таблиц, закрытый доступ к функциям для anon.
- Проверен XLSX с обратным чтением: числа сохраняются числами, пользовательские строки не превращаются в формулы.
- Vite production-сборка с тестовой публичной конфигурацией успешна. Тестовая конфигурация не включена в исходники или `.env`.
- `npm audit --omit=dev`: 0 известных уязвимостей зависимостей по текущей базе npm. Для транзитивного uuid задан override 11.1.1.
- Браузерная визуальная проверка не завершена: локальный Chromium не запускается в этой среде (ошибка EGL/Vulkan). Интерактивный интерфейс необходимо проверить после доступного браузерного запуска.
- Живые Supabase Auth, Storage, миграции и GitHub Pages не проверены: новый облачный проект и репозиторий ещё не созданы. Supabase Advisors нужно выполнить после применения миграции.

Сборка подготовлена для пилотного развёртывания; завершённой публикацией или полной реализацией модели v5 не является.

## Облачная база

Проект Supabase `pto-system` создан, обе миграции применены. На живой базе успешно проверены RPC, изоляция инженера, назначение объекта и открытие периода. Проверка выполнялась в транзакции с rollback; тестовые пользователи и объекты не сохранены. Bucket закрыт; все 11 таблиц public используют RLS. Security Advisor сообщил только INFO о закрытой внутренней таблице идемпотентности без клиентских политик — это намеренный запрет доступа. Индексы внешних ключей добавлены по Performance Advisor. Вход Auth и загрузка через Storage HTTP пока не проверены. GitHub/Pages ожидают завершения входа в браузере.
